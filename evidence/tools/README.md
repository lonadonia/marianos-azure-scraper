# The operator's tools, as used for these stages

These scripts are Hamza's own operator tools for the live stages of 1.10.0rc6 on Hamza's VM. They are **not part of
the collector** (that is [`../../source/`](../../source/), 1.10.0rc6) and are published so that each evidence file
can be traced to the code that wrote it. Private identifiers are masked as everywhere else
([`../../manifests/REDACTIONS.csv`](../../manifests/REDACTIONS.csv)). No tool holds a credential: the provider key is
read by the collector from its own 0600 file on the VM. The workstation reaches the VM through a private SSH helper
(`vm.sh`, not published: it holds the VM's address and the key's path); every `tools/vm.sh "..."` in these scripts
is one SSH command.

[`INSTALLED_ON_THE_VM.csv`](INSTALLED_ON_THE_VM.csv): each copy installed on the VM (the harness, the stops, the
evidence collector, the walkthrough runner, the stage definitions) compared by SHA-256 with the private source
these published copies come from, read as root after the last stage: all SAME.
